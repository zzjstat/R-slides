## English

This repository contains R lab slides used by Zejing Zheng as a teaching assistant for **Introduction to Statistics B** at Beijing Normal University. It includes eight slide decks and a review deck. **The slides are written in Chinese.** Topics range from R and RStudio basics to data structures, programming, simulation, descriptive statistics, inference, and linear regression.

Select **PDF** to open a slide deck directly. The source links lead to the corresponding folders containing the LaTeX files and supporting images.
