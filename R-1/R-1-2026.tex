\begin{frame}{R 软件简介}
  R 用于统计计算、数据分析和绘图。
  \begin{itemize}
    \item R 是 S 语言的一种实现，由 \mbox{Robert Gentleman}、\mbox{Ross Ihaka} 等开发。
    \item R 是免费软件，源代码公开。
    \item 教材使用 R 完成统计计算和随机现象模拟。
  \end{itemize}
  \note{教材第 11 页，附录开头。本讲教学范围为教材印刷第 11--22、28--29 页中的入门部分。第二讲继续学习其他向量操作、矩阵和数据框。本页仅介绍软件背景，不展开统计模型或编程语言历史。}
\end{frame}

\begin{frame}{R 脚本的创建与保存}
  脚本是保存 R 代码的文本文件。
  \begin{enumerate}
    \item 点击 \code{File > New File > R Script}。
    \item 在 Source 中输入代码。
    \item 点击 \code{File > Save}，选择保存文件夹。
    \item 将文件命名为 \code{R1-practice.R}。
  \end{enumerate}
  \vspace{0.5em}
  \begin{itemize}
    \item 保存快捷键：Windows 为 \code{Ctrl + S}，\par
      macOS 为 \code{Command + S}。
    \item 文件名旁的 \code{*} 表示修改尚未保存。
  \end{itemize}
  \note{教材第 14 页，编辑窗口中代码的保存和未保存标记。现行文件操作：https://docs.posit.co/ide/user/ide/guide/ui/files.html。}
\end{frame}

\begin{frame}{R 代码的运行}
  \begin{itemize}
    \item 在 Source 中选中代码，点击 \code{Run}。
    \item 也可运行当前行：\par
      Windows 使用 \code{Ctrl + Enter}。\par
      macOS 使用 \code{Command + Enter}。
    \item 在 Console 中直接输入命令，按 Enter 运行。
    \item 在 Console 中查看结果。
  \end{itemize}
  \vfill
  保存脚本与运行代码是两个操作。\par 运行代码后仍需保存文件。
  \note{教材第 16--17 页。教材采用旧版 Ctrl+r，本讲使用当前 RStudio 的 Run 和默认运行快捷键。官方说明：https://docs.posit.co/ide/user/ide/guide/code/execution.html。}
\end{frame}

\begin{frame}[fragile]{代码与输出}
  \inputlabel
\begin{lstlisting}
1 + 1
\end{lstlisting}
  \outputlabel
\begin{lstlisting}[style=output]
[1] 2
\end{lstlisting}
  \begin{itemize}
    \item 只输入代码 \code{1 + 1}，输出由 R 自动显示。
    \item \code{[1]} 表示本行结果从第 1 个元素开始显示。
    \item Console 中的结果不会自动写入脚本。
  \end{itemize}
  \note{输入输出见教材第 11--16 页；算术运算见第 28 页。教材第 20--21 页还解释分行输出编号，此处仅辨认单个结果的输出。}
\end{frame}

\begin{frame}[fragile]{基本运算}

\begin{frame}[fragile]{函数调用}
  R 提供了完成特定计算的函数。\par 函数名后的圆括号中填写输入值。
  \inputlabel
\begin{lstlisting}
sin(10)
\end{lstlisting}
  \outputlabel
\begin{lstlisting}[style=output]
[1] -0.5440211
\end{lstlisting}
  \begin{itemize}
    \item \code{sin()} 是正弦函数。
    \item 本例中，10 是传给函数的参数。
    \item 输入不同参数，函数会计算相应结果。
  \end{itemize}
  \note{教材第 15--16 页的原例。此处学习调用函数的方法，不展开三角函数推导。R 的三角函数参数单位为弧度。}
\end{frame}

\begin{frame}[fragile]{变量与赋值}

\begin{frame}[fragile]{变量的使用与更新}
  \inputlabel

x <- 5
y <- x
x <- 8

x
y
\end{lstlisting}
  两行输出依次为 8 和 5。
  \begin{itemize}
    \item \code{y <- x} 将当时 \code{x} 的值保存到 \code{y}。
    \item 重新给 \code{x} 赋值后，\code{y} 仍为 5。
    \item Environment 中会显示这些变量。
  \end{itemize}

\begin{frame}{变量命名}
  \begin{itemize}
    \item 本课程采用英文字母开头的名称，\par 后面可加数字。
    \item 名称区分大小写，\code{x} 与 \code{X} 是不同变量。
    \item 不以数字开头，例如 \code{1x} 不能作为普通变量名。
    \item 避免使用已有函数名和系统常量名，例如 \mbox{\code{sin}、\code{pi}}。
  \end{itemize}
  \vspace{0.5em}
  常见名称：\code{x}、\code{y}、\code{x1}。
  \note{教材第 16 页的命名、大小写和不覆盖系统变量。只采用教材中的简单名称。}
\end{frame}
